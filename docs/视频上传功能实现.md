# 菜谱视频上传 — 后端实现文档

## 整体流程

```
前端选视频 → POST /upload/video → 后端校验类型/大小 → 存本地磁盘 → 返回URL
                                                                      ↓
                                                    Recipe实体新增video字段存URL
```

---

## 1. 数据库加 video 列

在你的 MySQL（阿里云 RDS）上执行：

```sql
ALTER TABLE recipe ADD COLUMN video VARCHAR(500) DEFAULT NULL COMMENT '视频URL';
```

> 一个菜谱最多一个视频，所以用单字段存 URL 字符串就够了，不需要 JSON 数组。

---

## 2. Recipe 实体加字段

**文件**：`src/main/java/.../entity/Recipe.java`

在 `coverImages` 字段下面加一行：

```java
@Schema(description = "视频URL")
private String video;
```

MyBatis-Plus 会自动把数据库列名 `video` 映射到这个驼峰命名的字段。因为所有 Mapper XML 里写的都是 `SELECT r.*`，所以新增列会自动带出来，**不需要改任何 SQL**。

## 3. 文件上传控制器 — 新增视频接口

**文件**：`src/main/java/.../controller/FileUploadController.java`

### 3.1 加视频存储目录

在类顶部，图片目录常量旁边加一行：

```java
private static final String VIDEO_DIR =
    Paths.get(System.getProperty("user.dir"), "uploads", "recipes", "video").toString();
```

`System.getProperty("user.dir")` 是 JVM 启动时的工作目录，等于你项目的根目录。最终视频存在 `项目根目录/uploads/recipes/video/` 下。

### 3.2 加视频上传接口

```java
@PostMapping("/video")
public String uploadVideo(HttpServletRequest request) {
    // 1. 把普通 HttpServletRequest 转成能读文件的 MultipartHttpServletRequest
    MultipartHttpServletRequest multi = (MultipartHttpServletRequest) request;
    MultipartFile file = multi.getFile("file");

    if (file == null || file.isEmpty()) {
        throw new RuntimeException("请选择视频文件");
    }

    // 2. 校验文件类型（白名单，防止上传恶意文件）
    String contentType = file.getContentType();
    List<String> allowedTypes = List.of("video/mp4", "video/webm", "video/quicktime");
    if (contentType == null || !allowedTypes.contains(contentType)) {
        throw new RuntimeException("不支持的视频格式，仅支持 mp4 / webm / mov");
    }

    // 3. 校验文件大小（限制 100MB）
    long maxSize = 100L * 1024 * 1024;  // 100MB 转成字节
    if (file.getSize() > maxSize) {
        throw new RuntimeException("视频不能超过 100MB");
    }

    // 4. 生成唯一文件名，写入磁盘
    String name = UUID.randomUUID().toString().replace("-", "") + ".mp4";
    File dir = new File(VIDEO_DIR);
    if (!dir.exists()) {
        dir.mkdirs();   // mkdirs 会连带创建所有不存在的父目录
    }
    file.transferTo(new File(dir, name));

    // 5. 返回可访问的相对路径
    return "/uploads/recipes/video/" + name;
}
```

### 代码解释 — 为什么这么写

**第1步：`MultipartHttpServletRequest`**

前端用 `FormData` 传视频，HTTP 请求的 Content-Type 会变成 `multipart/form-data`。Spring 的普通 `HttpServletRequest` 拿不到里面的文件，必须转成 `MultipartHttpServletRequest` 才能调 `getFile("file")` 取出文件。

> 注意：前端 `FormData` append 时的 key 必须和这里 `getFile("file")` 的参数名一致。如果前端写 `form.append('video', file)`，那后端就要写 `getFile("video")`。

**第2步：MIME 类型白名单**

`file.getContentType()` 不是靠文件扩展名判断的，而是浏览器在发送文件时根据文件实际内容设置的 MIME 类型：
- `video/mp4` — MP4 视频
- `video/webm` — WebM 视频
- `video/quicktime` — MOV 视频（Apple 格式）

用白名单（只允许已知安全类型）而不是黑名单（排除危险类型），这是安全原则。攻击者可能上传 `.jsp` 文件到服务器然后执行，所以必须只放行你明确需要的类型。

**第3步：大小限制**

`file.getSize()` 返回的是字节数。100MB = 100 × 1024 × 1024 字节。这个限制比 Spring 配置的 `max-file-size` 更灵活——你可以在代码里对不同接口设不同大小（图片 10MB、视频 100MB）。

**第4步：文件名 + 存储**

- `UUID.randomUUID().toString().replace("-", "")` — 生成类似 `a1b2c3d4e5f67890` 的无冲突唯一名。不用原始文件名是防止用户上传 `../../etc/passwd` 这样的路径遍历攻击。
- 统一存为 `.mp4` — 不管用户上传什么格式，扩展名都写 `.mp4`。大部分手机录的视频本身就是 MP4 容器格式。
- `dir.mkdirs()` — 等同于 `mkdir -p`，目录存在就不做事，不存在就连带父目录一起创建。

**第5步：返回路径**

返回的是 `/uploads/recipes/video/xxx.mp4`，这个路径能被 `WebmvcConfig` 的静态资源映射命中（`/uploads/**` → `file:./uploads/`），所以前端直接用这个 URL 就能播放，不需要额外写接口。

## 4. 调大上传大小限制

**文件**：`src/main/resources/application.properties`

把原来的：

```properties
spring.servlet.multipart.max-file-size=20MB
spring.servlet.multipart.max-request-size=50MB
```

改成：

```properties
spring.servlet.multipart.max-file-size=120MB
spring.servlet.multipart.max-request-size=150MB
```

`max-file-size` 是单个文件上限，`max-request-size` 是一次请求的总上限（可能包含多个文件 + 其他表单字段）。

> 为什么设这么大？视频 100MB + 几张图片每个 10MB，一次请求最多可能 150MB，留点余量。

## 5. 前端怎么对接（简要）

你后端写好后，前端需要改这几个地方：

### 5.1 API 层 — `frontend/src/api/recipe.js`

```js
export function uploadVideo(file) {
  const form = new FormData()
  form.append('file', file)   // key 必须和后端 getFile("file") 一致
  return request.post('/upload/video', form)
}
```

### 5.2 发布页 — `UploadRecipeView.vue`

加一个视频选择的 `<input>` 和上传逻辑，提交时把返回的 URL 放进 `data.video`：

```js
const videoUrl = ref('')

async function onVideoChange(e) {
  const file = e.target.files[0]
  if (!file) return
  const res = await uploadVideo(file)
  videoUrl.value = res.data   // 后端返回的 "/uploads/recipes/video/xxx.mp4"
}

// 提交时
const data = {
  // ...其他字段
  video: videoUrl.value,
}
await createRecipe(data)
```

### 5.3 详情页 — `RecipeDetail.vue`

```html
<div v-if="recipe.video" class="video-wrap">
  <video :src="recipe.video" controls preload="metadata"
         style="width:100%; max-height:400px; border-radius:12px">
  </video>
</div>
```
